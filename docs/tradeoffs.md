# 数据流转追踪：设计取舍

本文交代追踪页面 (`trace/web/index.html`) 背后两处关键取舍。调用图由
`trace/analyzer.py` 纯静态生成到 `trace/graph.json`，服务端 `trace/server.py`
只读该文件与项目内源码，不导入、不执行 `stock_dashboard.py`。

## 1. 缓存键：挂 ticker，还是叠加周期与参数

**结论：缓存键叠加周期与参数，不只挂 ticker。**

`load_stock_data(symbol, period="1y")` 使用 `@st.cache_data(ttl=900)`，
Streamlit 以全部入参序列化后的值生成缓存键，实际键形如：

```
cache:cache_data:load_stock_data(symbol, period)
```

- 只挂 ticker（例如 `f"AAPL"`）：实现简单，同一支股票切换
  `1mo → 5y` 时会错误复用 1 个月的数据；周期、拆复权、数据源参数不同
  却共用一份副本，页面结论会被旧周期污染。
- 叠加周期与参数（本实现）：`("AAPL", "1y")` 与 `("AAPL", "5y")`
  是两条独立缓存，切换周期触发一次重取，之后都走复用。代价是缓存条目数
  随「ticker × 周期」组合增长，因此用 `ttl=900` 限寿命，并保留侧栏
  「Refresh Data」按钮调用 `st.cache_data.clear()` 作显式失效。

追踪页面中该函数被标为绿色「复用区」，条目里同时列出缓存键与失效条件
（入参变化 / ttl 到期 / 显式 clear / 进程退出）。其它函数没有缓存装饰器，
属于橙色「重算区」；从复用区进入重算区（或反向）的本地调用边标为红色
「跨分界」，目前即 `StockAnalyzer.fetch_stock_data → load_stock_data`。

`st.session_state` 的键（`last_fetch_ticker`、`last_fetch_period`）
不是缓存键：它们只记录“最近一次实际使用的键”，用于排查命中了哪条缓存，
不参与缓存命中判定。

## 2. 整体重跑与阻塞式调用如何并存

Streamlit 的执行模型是**每次交互整体重跑脚本**：点 ticker、切周期、勾复选框
都会从 `main()` 重新执行一遍。行情获取是**阻塞式**调用
（`yf.Ticker(...).history(...)` 同步等网络），两者并存靠三层分工：

1. **跨重跑复用**：阻塞调用被收进 `@st.cache_data` 的 `load_stock_data`。
   脚本整体重跑时，调用语句照常执行，但参数未变就直接返回缓存对象，
   阻塞网络只在首次/失效后真正发生一次。整体重跑负责重新拼装 UI，
   缓存负责让昂贵的阻塞调用不重复付出代价。
2. **重跑内的阻塞体验**：真正需要等待的 `with st.spinner(...)` 块在
   调用图里标成独立分区（tab/checkbox/spinner），页面标签页中可按这些
   分区过滤，看清哪段交互会阻塞、哪段只是纯计算重绘。
3. **不把阻塞调用塞进隐式全局状态**：`analyzer = StockAnalyzer()`
   每次重跑新建，模型训练 (`RandomForestRegressor.fit`) 是 CPU 密集的
   阻塞计算，按当前设计随重算区每次重跑；没有用缓存掩盖它，因为训练结果
   依赖刚取回的数据且用户明确期望刷新预测。未来若要复用，应加独立的
   `@st.cache_resource`（资源缓存，键同样叠加特征参数），而不是复用
   数据缓存——数据值可序列化、模型对象不可序列化，混用会让失效语义变模糊。

因此「整体重跑」与「阻塞式调用」不是互斥关系：重跑是 UI 语义，
阻塞是调用语义；缓存装饰器是两者之间的节流阀，而调用图页面把这条
分界线（复用区/重算区/跨分界红边）显式画了出来。

## 静态分析的边界

- 动态属性（`getattr`、来源类型无法确定的 `.attr`）与间接调用
  （下标取可调用对象、任意表达式被调用）一律记为「不可解析」，
  不猜测目标。
- 不可解析调用占全部调用的比例超过 15% 时，`graph.json` 中
  `stats.threshold_exceeded=true`，页面整体转灰且不给出数据流转结论。
- 落不到具体源码行的条目不展示。
- 增量扫描只重解析变更模块，合并后必须与全量重扫**逐边一致**；
  未变更模块里仍存在间接/动态调用（可能跨模块命中刚变更的模块、
  残留旧边）时直接退回全量。
